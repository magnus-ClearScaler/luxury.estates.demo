# Naming the house

Checked on 2026-10-09. Nothing was registered, reserved or bought.

## Method

- **.com**: `whois -h whois.verisign-grs.com` (registry of record). "No match" means unregistered.
- **.fr**: `whois -h whois.nic.fr` (AFNIC). "NOT FOUND" means unregistered.
- **.estate / .house**: Vercel `get_bulk_availability` (registry lookup, read only). Every shortlisted name came back available on all four TLDs.
- **Conflicts**: web searches on the exact name, plus words like immobilier, real estate, hotel and villa. Where a .com is taken, I looked at who holds it.
- **Trademarks**: INPI (data.inpi.fr) returned a Cloudflare block, and the TMview/EUIPO API returned nothing from a script. WIPO Brand Database needs JavaScript. **No registry search was completed.** Before the name is used publicly, run a manual TMview search (classes 36 and 43, offices EM, FR, WO) on the top two names.
- **Instagram**: every handle returns HTTP 200 behind the login wall, so the result is inconclusive. Check by hand when logged in.
- **Pronunciation and meaning**: reviewed for English, French, Italian, Spanish, Norwegian and Arabic speakers.

### Pronunciation (EN / FR / NO / AR speakers)

- Mont'Albe: mon-TALB. Easy in all four. The Arabic "b" and "l" are native sounds.
- Aube'Mar: ohb-MAR. Easy in all four. English speakers may say "awb", which still sounds fine.
- Mont'Avisio: mon-ta-VEE-zyo. Easy in FR and NO, fine in EN and AR.
- Maison d'Aurèle: meh-ZON doh-REL. English speakers flatten it but it stays elegant; fine in AR.
- Maison Calèu: ka-LEH-oo. English and Norwegian speakers hesitate.
- Mont'Estel: mon-tes-TEL. Easy in all four.
